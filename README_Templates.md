# HF template designs (no code changes, no version change)

Designs: Reel, Datasheet, Afterhours, Edition.

## Try one

1. Copy `Resources/HF_Template_<Design>.txt` into your `Resources/` folder.
2. Set Template file (`outputs.template_file`) to that name.
   It works straight away with your current icons. It looks right once step 3 is done.

## Add its images (optional)

3. Upload `Template_Assets/<Design>/*.png` to Hamster, then in `Resources/BBCode_Images.json`
   point each key to the matching file's path. File names equal the JSON keys
   (`bg.png` -> `"bg"`, `1080p.png` -> `"1080p"`, `tpdb_button.png` -> `"tpdb_button"`).
   Leave `desc_button`, `release_date_button`, `performers_button`, `mediainfo_button`
   and `screens_button` in the JSON: the code still reads them, the templates just do not show them.
   Keep a copy of your current JSON. Only one image set is active at a time.

## MediaInfo

Reel and Afterhours: collapsed. Datasheet: open. Edition: left out.
